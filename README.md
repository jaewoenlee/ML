Student workflow / 학생 실습 방법

1. Open the notebook in Colab using a link above.
2. Choose File → Save a copy in Drive (파일 → Drive에 사본 저장).
3. Rename your copy, for example `threshold_mse_yourname.ipynb`. Work in the new tab; its URL should contain `/drive/`.
4. Save your work in your own Drive. If GitHub submission is required, use your own repository or fork and select that destination explicitly.

GitHub contains the instructor's master notebooks. Opening or running a notebook in Colab does not save changes back to GitHub. “Save a copy to GitHub” can update an existing file when an authorized writer selects the same repository, branch, and path; the word “copy” does not protect the master.
